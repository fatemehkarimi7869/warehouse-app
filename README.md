# سامانه مدیریت انبار

این نسخه شامل:
- موجودی اولیه محصول و محاسبه موجودی فعلی
- ثبت تولید با تاریخ شمسی و بچ/سریال
- ثبت خروج با تاریخ شمسی، استان، شهر، باربری و بچ/سریال
- ثبت فاکتور فروش با تاریخ فاکتور و موعد تحویل مشتری
- برنامه‌ریزی تولید روزانه بر اساس **موعد تحویل**، نه تاریخ ثبت سفارش
- فاصله قابل تنظیم برای شروع تولید و زمان آماده‌سازی/ارسال
- ظرفیت تولید روزانه برای هر محصول
- مدیریت کاربران و دسترسی مشاهده/ثبت برای هر بخش

## منطق برنامه‌ریزی تولید

اگر امروز فاکتور ثبت شود ولی مشتری یک یا دو هفته بعد تحویل بخواهد، سیستم تولید را برای همان روز سفارش قرار نمی‌دهد. برنامه تولید با توجه به موعد تحویل، تعداد روز کاری قبل از موعد و ظرفیت تولید روزانه محصول ساخته می‌شود.

تنظیمات پیش‌فرض:
- شروع تولید: ۷ روز کاری قبل از موعد
- زمان آماده‌سازی/ارسال: ۲ روز کاری قبل از موعد
- جمعه روز غیرکاری است

اگر ظرفیت تولید روزانه محصول صفر باشد، محدودیت ظرفیت برای آن محصول اعمال نمی‌شود.
